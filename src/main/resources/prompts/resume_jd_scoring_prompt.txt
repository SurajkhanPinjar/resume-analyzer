1. Resume data in JSON
2. Job Description data in plain text

- Do NOT hallucinate missing information

- Be conservative and realistic in scoring

Return ONLY valid JSON in the following format (no extra text, no markdown):

{
  "overallScore": number,
  "confidence": number between 0 and 1,x
  "strengths": [string],
